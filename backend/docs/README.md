# Backend Docs

Este diretorio concentra a documentacao operacional e funcional do backend.

## Como navegar

- `00_backend_completo.txt`: visao geral da arquitetura e dos modulos principais
- `01_autenticacao.txt` a `08_websocket.txt`: contratos por area funcional
- `09_regras_negocio_dashboard.txt` a `14_regras_negocio_websocket.txt`: regras de negocio por modulo
- `15_integração_api_externa.txt`: documento canonico de integracoes externas

## Notas

- O checklist operacional de homologacao fica em `../CHECKLIST_HOMOLOGACAO.md` na raiz do projeto.
- O arquivo `15_integração_api_externa.txt` e a fonte principal para integracoes com Binance, AwesomeAPI, webhooks e fluxo de treinamento.
- O arquivo `15_integracao_api_externa_impl.md` e apenas um resumo curto da implementacao aplicada.
- Artefatos legados duplicados com nome corrompido foram removidos para evitar ambiguidade.
- Os comandos operacionais de apoio ficam em `comandos.txt`, alinhados com o fluxo atual do projeto.
