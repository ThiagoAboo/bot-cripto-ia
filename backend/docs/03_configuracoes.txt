1. API: GET /api/configurations
-------------------------------------------------------------------------------

Descrição: Carrega todas as configurações do usuário

HEADERS:
  Authorization: Bearer {token}

RESPONSE (200 - Sucesso):
{
  "success": true,
  "data": {
    "exchangeApiKeys": {
      "exchange": "binance",
      "apiKey": "xxxxx",
      "secretKey": "xxxxx"
    },
    "botParameters": {
      "riskManagement": {
        "stopLossPercent": 5.0,
        "takeProfitPercent": 10.0,
        "leverage": 1,
        "maxTradeAmount": 1000,
        "maxTradeAmountUnit": "USDT"
      },
      "allowedPairs": ["BTC/USDT", "ETH/USDT", "SOL/USDT"],
      "fees": {
        "discountUsdtPercent": 0.075,
        "discountBnbPercent": 0.075,
        "minBnbBalance": 0.01
      },
      "advanced": {
        "mode": "spot",
        "orderType": "market",
        "slippagePercent": 0.5
      },
      "strategies": [
        {
          "id": "strategy_scalper",
          "name": "Scalper V2",
          "strategyType": "scalper",
          "isActive": true,
          "parameters": {
            "timeframe": "1m",
            "maxSpread": 0.1,
            "minVolume": 100000
          }
        }
      ]
    }
  }
}

TABELAS ENVOLVIDAS:
- Configuration

CAMPOS NA TABELA Configuration (mapeamento):

| Campo Frontend                    | Campo Banco                     |
|-----------------------------------|---------------------------------|
| exchangeApiKeys.exchange          | exchange                        |
| exchangeApiKeys.apiKey            | apiKey                          |
| exchangeApiKeys.secretKey         | secretKey                       |
| botParameters.riskManagement.stopLossPercent | stopLossPercent       |
| botParameters.riskManagement.takeProfitPercent | takeProfitPercent     |
| botParameters.riskManagement.leverage | leverage                      |
| botParameters.riskManagement.maxTradeAmount | maxTradeAmount          |
| botParameters.riskManagement.maxTradeAmountUnit | maxTradeAmountUnit    |
| botParameters.allowedPairs        | allowedPairs (JSON)             |
| botParameters.fees.discountUsdtPercent | discountUsdtPercent         |
| botParameters.fees.discountBnbPercent | discountBnbPercent          |
| botParameters.fees.minBnbBalance  | minBnbBalance                   |
| botParameters.advanced.mode       | mode                            |
| botParameters.advanced.orderType  | orderType                       |
| botParameters.advanced.slippagePercent | slippagePercent             |
| botParameters.strategies          | strategies (JSON)               |

-------------------------------------------------------------------------------
2. API: PUT /api/configurations
-------------------------------------------------------------------------------

Descrição: Salva todas as configurações do usuário

HEADERS:
  Authorization: Bearer {token}
  Content-Type: application/json

REQUEST BODY: (mesma estrutura do GET)

RESPONSE (200 - Sucesso):
{
  "success": true
}

RESPONSE (400 - Validação):
{
  "success": false,
  "error": "stopLossPercent deve ser entre 0 e 50"
}

TABELAS ENVOLVIDAS:
- Configuration (cria ou atualiza)

CAMPOS ATUALIZADOS:
- Todos os campos da tabela Configuration

VALIDAÇÕES:

| Campo                    | Validação                                    |
|--------------------------|----------------------------------------------|
| stopLossPercent          | 0 < valor ≤ 50                               |
| takeProfitPercent        | 0 < valor ≤ 100                              |
| leverage                 | 1 ≤ valor ≤ 125                              |
| maxTradeAmount           | > 0                                          |
| discountUsdtPercent      | 0 ≤ valor ≤ 1                                |
| discountBnbPercent       | 0 ≤ valor ≤ 1                                |
| minBnbBalance            | ≥ 0                                          |
| slippagePercent          | 0 ≤ valor ≤ 5                                |
| allowedPairs             | Array de strings (pares válidos)             |
| strategies               | Array com estrutura válida                   |

-------------------------------------------------------------------------------
3. API: POST /api/configurations/test-connection
-------------------------------------------------------------------------------

Descrição: Testa as credenciais da API com a exchange

HEADERS:
  Authorization: Bearer {token}
  Content-Type: application/json

REQUEST BODY:
{
  "exchange": "binance",
  "apiKey": "xxxxx",
  "secretKey": "xxxxx"
}

RESPONSE (200 - Sucesso):
{
  "success": true,
  "message": "Conexão estabelecida com sucesso!"
}

RESPONSE (401 - Falha):
{
  "success": false,
  "message": "Chaves de API inválidas"
}

TABELAS ENVOLVIDAS:
- Nenhuma (apenas comunicação com exchange)

FLUXO:
1. Tentar fazer uma chamada autenticada à exchange (ex: GET /api/v3/account)
2. Se sucesso, retornar true
3. Se falha, retornar false com mensagem de erro

-------------------------------------------------------------------------------
4. API: GET /api/exchange/pairs
-------------------------------------------------------------------------------

Descrição: Retorna lista de pares disponíveis na exchange

HEADERS:
  Authorization: Bearer {token}

QUERY PARAMS:
  quoteAsset: string (opcional, padrão: 'USDT')

RESPONSE (200 - Sucesso):
{
  "success": true,
  "data": [
    "BTC/USDT",
    "ETH/USDT",
    "SOL/USDT",
    "BNB/USDT",
    "XRP/USDT",
    "DOGE/USDT",
    "ADA/USDT",
    "AVAX/USDT",
    "DOT/USDT",
    "LINK/USDT"
  ]
}

TABELAS ENVOLVIDAS:
- Nenhuma (dados da exchange)

OBSERVAÇÃO: Pode ser cacheadado por 5 minutos para evitar chamadas excessivas

5. MODELO DE DADOS - Configuration
-------------------------------------------------------------------------------

TABELA: Configuration

CAMPO                    | TIPO    | OBRIG | DESCRIÇÃO
-------------------------|---------|-------|----------------------------------
id                       | String  | Sim   | UUID - Chave primária
userId                   | String  | Sim   | FK para User (unique)
exchange                 | String  | Sim   | binance/kucoin/bybit
apiKey                   | String  | Sim   | Chave da API (criptografada)
secretKey                | String  | Sim   | Chave secreta (criptografada)
stopLossPercent          | Float   | Sim   | Stop-loss percentual
takeProfitPercent        | Float   | Sim   | Take-profit percentual
leverage                 | Int     | Sim   | Alavancagem (1-125)
maxTradeAmount           | Float   | Sim   | Valor máximo por trade
maxTradeAmountUnit       | String  | Sim   | USDT ou percent
allowedPairs             | String  | Sim   | JSON array
discountUsdtPercent      | Float   | Sim   | Desconto USDT
discountBnbPercent       | Float   | Sim   | Desconto BNB
minBnbBalance            | Float   | Sim   | Saldo mínimo BNB
mode                     | String  | Sim   | spot/futures
orderType                | String  | Sim   | market/limit
slippagePercent          | Float   | Sim   | Slippage percentual
strategies               | String  | Sim   | JSON array
createdAt                | DateTime| Sim   | Data criação
updatedAt                | DateTime| Sim   | Data atualização
