2.4 AUTENTICAÇÃO E ASSINATURA
-------------------------------------------------------------------------------

Todas as requisições autenticadas devem incluir:
1. Header: X-MBX-APIKEY = API_KEY
2. Parâmetros: timestamp e signature

Geração da signature:
signature = HMAC_SHA256(queryString, SECRET_KEY)

Exemplo em TypeScript:
-------------------------------------------------------------------------------
import crypto from 'crypto'

function generateSignature(queryString: string, secretKey: string): string {
  return crypto
    .createHmac('sha256', secretKey)
    .update(queryString)
    .digest('hex')
}

async function binanceRequest(
  endpoint: string,
  method: 'GET' | 'POST' | 'DELETE',
  params: Record<string, any>,
  apiKey: string,
  secretKey: string
) {
  const timestamp = Date.now()
  const queryParams = { ...params, timestamp, recvWindow: 5000 }
  const queryString = new URLSearchParams(queryParams).toString()
  const signature = generateSignature(queryString, secretKey)
  
  const url = `https://api.binance.com${endpoint}?${queryString}&signature=${signature}`
  
  const response = await fetch(url, {
    method,
    headers: { 'X-MBX-APIKEY': apiKey }
  })
  
  return response.json()
}

2.5 RATE LIMITING E CONTROLES
-------------------------------------------------------------------------------

Limites da Binance:
| Tipo de requisição | Limite | Janela   | Ação em caso de excesso |
|--------------------|--------|----------|--------------------------|
| Weight total       | 1200   | 1 minuto | Aguardar e retentar      |
| Ordens             | 50     | 10s      | Delay de 10s             |
| WebSocket          | 1024   | 5 minutos| Fechar e reconectar      |

Implementação do Rate Limiter:
-------------------------------------------------------------------------------
class BinanceRateLimiter {
  private requests: number[] = []
  private orderRequests: number[] = []
  private readonly maxWeight = 1200
  private readonly maxOrders = 50
  private readonly windowMs = 60000
  private readonly orderWindowMs = 10000

  async waitForWeight(weight: number = 1): Promise<void> {
    const now = Date.now()
    this.requests = this.requests.filter(t => now - t < this.windowMs)
    
    let currentWeight = this.requests.length
    if (currentWeight + weight > this.maxWeight) {
      const oldest = this.requests[0]
      const waitTime = this.windowMs - (now - oldest)
      await new Promise(resolve => setTimeout(resolve, waitTime))
      return this.waitForWeight(weight)
    }
    
    for (let i = 0; i < weight; i++) {
      this.requests.push(now)
    }
  }

  async waitForOrder(): Promise<void> {
    const now = Date.now()
    this.orderRequests = this.orderRequests.filter(t => now - t < this.orderWindowMs)
    
    if (this.orderRequests.length >= this.maxOrders) {
      const oldest = this.orderRequests[0]
      const waitTime = this.orderWindowMs - (now - oldest)
      await new Promise(resolve => setTimeout(resolve, waitTime))
      return this.waitForOrder()
    }
    
    this.orderRequests.push(now)
  }
}

2.6 TRATAMENTO DE ERROS
-------------------------------------------------------------------------------

| Código | Erro                         | Ação do Sistema                          |
|--------|------------------------------|------------------------------------------|
| -1000  | Parâmetro inválido           | Validar parâmetros antes de enviar       |
| -1003  | Rate limit excedido          | Aguardar e tentar novamente (backoff)    |
| -1021  | Timestamp inválido           | Sincronizar tempo com servidor           |
| -1022  | Assinatura inválida          | Regenerar signature                      |
| -2010  | Saldo insuficiente           | Notificar frontend, não tentar novamente |
| -2011  | Ordem não encontrada         | Verificar ID e tentar novamente          |
| -2013  | Ordem não existe             | Retornar erro ao frontend                |
| -2014  | API Key inválida             | Notificar usuário para reconfigurar      |

3.4 CACHE DE COTAÇÕES
-------------------------------------------------------------------------------

Implementação do Cache:
-------------------------------------------------------------------------------
interface RateCache {
  rate: number
  timestamp: number
  pctChange: number
}

const rateCache = new Map<string, RateCache>()
const CACHE_DURATION = 60000 // 1 minuto

async function getExchangeRate(from: string, to: string): Promise<RateCache> {
  const cacheKey = `${from}-${to}`
  const cached = rateCache.get(cacheKey)
  
  if (cached && Date.now() - cached.timestamp < CACHE_DURATION) {
    return cached
  }
  
  const rate = await fetchRateFromAPI(from, to)
  rateCache.set(cacheKey, rate)
  
  return rate
}

async function fetchRateFromAPI(from: string, to: string): Promise<RateCache> {
  const pair = `${from}-${to}`
  const url = `https://economia.awesomeapi.com.br/json/last/${pair}`
  
  const response = await fetch(url)
  const data = await response.json()
  
  const key = `${from}${to}`
  return {
    rate: parseFloat(data[key].bid),
    pctChange: parseFloat(data[key].pctChange),
    timestamp: Date.now()
  }
}

async function sendWebhook(event: string, data: any, retries: number = 3) {
  if (!process.env.WEBHOOK_ENABLED || process.env.WEBHOOK_ENABLED !== 'true') {
    return
  }

  const url = process.env.WEBHOOK_URL
  if (!url) return

  const payload = {
    event,
    timestamp: new Date().toISOString(),
    environment: process.env.NODE_ENV,
    data
  }

  for (let i = 0; i < retries; i++) {
    try {
      const response = await fetch(url, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(payload)
      })
      
      if (response.ok) {
        logger.info(`Webhook enviado: ${event}`)
        return
      }
    } catch (error) {
      logger.error(`Webhook falhou (tentativa ${i + 1}):`, error)
      await new Promise(resolve => setTimeout(resolve, 1000 * Math.pow(2, i)))
    }
  }
  
  logger.error(`Webhook falhou após ${retries} tentativas: ${event}`)
}

5.2 FLUXO DE DADOS POR TELA
-------------------------------------------------------------------------------

5.2.1 DASHBOARD

1. Frontend chama GET /api/dashboard/total-balance
2. Backend:
   - Busca saldos no banco (tabela Balance)
   - Chama Binance API para cotação atual
   - Calcula totais convertidos para BRL
3. Retorna para Frontend:
   - totalBrl
   - dailyProfitBrl
   - totalPnlBrl
   - hitRate
   - usdtBrlRate

Tempo de resposta esperado: < 500ms
Cache: Dados de cotação cacheados por 5s

5.2.2 GRÁFICO DE PERFORMANCE

1. Frontend chama GET /api/dashboard/performance?period=7d
2. Backend:
   - Busca histórico de saldos do banco (tabela BalanceHistory)
   - Se não houver dados suficientes, calcula a partir de transações
3. Retorna para Frontend:
   - Array de { timestamp, balance }

Tempo de resposta esperado: < 200ms

5.2.3 TRANSAÇÕES - GRÁFICO CANDLESTICK

1. Frontend chama GET /api/exchange/candles?pair=BTC/USDT&period=1h&limit=100
2. Backend:
   - Verifica cache (5 minutos)
   - Se cache expirado, chama Binance API
   - Converte dados para formato do frontend
3. Retorna para Frontend:
   - Array de { timestamp, open, high, low, close, volume }

Tempo de resposta esperado: < 300ms (com cache), < 1000ms (sem cache)
Atualização: Frontend faz polling a cada 5 segundos

5.2.4 TRANSAÇÕES - ORDEM MANUAL

1. Frontend chama POST /api/orders
2. Backend:
   - Valida saldo no banco
   - Reserva saldo (atualiza Balance.reserved)
   - Chama Binance API para executar ordem
   - Atualiza saldos (Balance.available e Balance.total)
   - Registra transação (Transaction)
   - Emite WebSocket order:created
3. Retorna para Frontend:
   - Objeto Transaction

Tempo de resposta esperado: < 2000ms

5.2.5 TREINAMENTO IA - COLETA DE DADOS

1. Frontend chama POST /api/training/sessions
2. Backend:
   - Inicia job em background (Bull/Redis)
   - Coleta dados da Binance API:
     - Período: config.trainingPeriod
     - Pares: config.includedPairs
     - Timeframe: config.timeframe
   - Calcula indicadores técnicos
   - Prepara dataset
   - Inicia treinamento
3. Atualiza frontend via WebSocket:
   - training:metrics (a cada época)
   - training:log (a cada evento)
   - training:status (quando muda)

Tempo de coleta de dados: depende do período (pode levar minutos)

6.1 COLETA DE DADOS HISTÓRICOS
-------------------------------------------------------------------------------

Fonte: Binance API (GET /api/v3/klines)

Parâmetros de coleta:
- Pares: config.includedPairs (ex: ["BTC/USDT", "ETH/USDT"])
- Período: config.trainingPeriod (ex: 90 dias)
- Timeframe: config.timeframe (ex: 1h, 4h, 1d)

Volume de dados estimado:
- 1h timeframe: 24 pontos/dia x 90 dias = 2.160 pontos por par
- 4h timeframe: 6 pontos/dia x 90 dias = 540 pontos por par
- 1d timeframe: 90 pontos

6.2 INDICADORES TÉCNICOS CALCULADOS
-------------------------------------------------------------------------------

Os seguintes indicadores são calculados a partir dos dados brutos:

| Indicador | Fórmula                                    | Período padrão |
|-----------|--------------------------------------------|----------------|
| SMA       | Média móvel simples                        | 7, 14, 21, 50  |
| EMA       | Média móvel exponencial                    | 7, 14, 21, 50  |
| RSI       | 100 - (100 / (1 + RS))                     | 14             |
| MACD      | EMA(12) - EMA(26), com sinal EMA(9)        | 12, 26, 9      |
| BB        | Bandas de Bollinger (média ± 2*desvio)     | 20, 2          |
| Volume    | Volume negociado                           | -              |
| ATR       | Average True Range                         | 14             |
| OBV       | On-Balance Volume                          | -              |
| StochRSI  | (RSI - min(RSI)) / (max(RSI) - min(RSI))   | 14             |

6.3 FORMATO DO DATASET
-------------------------------------------------------------------------------

Dataset gerado para treinamento (formato CSV):

timestamp,open,high,low,close,volume,SMA_7,SMA_14,EMA_7,RSI,MACD,BB_upper,BB_lower
2024-01-01 00:00:00,62345,62500,62200,62400,1234.5,62300,62250,62350,65.2,12.3,63000,61800
2024-01-01 01:00:00,62400,62600,62300,62500,1456.7,62350,62300,62400,68.4,15.6,63200,62000
...

Colunas:
- timestamp: Data/hora do candle
- open, high, low, close, volume: Dados brutos
- SMA_7, SMA_14: Médias móveis
- EMA_7: Média exponencial
- RSI: Índice de força relativa
- MACD: Moving Average Convergence Divergence
- BB_upper, BB_lower: Bandas de Bollinger

6.4 PIPELINE DE DADOS
-------------------------------------------------------------------------------

Pipeline completo para treinamento:

1. Coleta de dados brutos da Binance
   │
   ▼
2. Validação e limpeza
   - Remover dados faltantes
   - Interpolar gaps pequenos (até 3 candles)
   - Remover outliers (valores > 3 desvios padrão)
   │
   ▼
3. Cálculo de indicadores técnicos
   - SMA, EMA, RSI, MACD, Bollinger Bands, etc.
   │
   ▼
4. Normalização
   - Min-Max scaling para cada feature
   - Range: [0, 1] ou [-1, 1]
   │
   ▼
5. Criação de sequências (para LSTM)
   - Tamanho da sequência: config.hyperparameters.windowSize (padrão: 60)
   - Passo: 1
   │
   ▼
6. Divisão treino/validação
   - Treino: 80% dos dados (mais antigos)
   - Validação: 20% dos dados (mais recentes)
   │
   ▼
7. Dataset pronto para treinamento

Exemplo de criação de sequências (LSTM):
-------------------------------------------------------------------------------
function createSequences(data: number[][], windowSize: number): { X: number[][][], y: number[][] } {
  const X = []
  const y = []
  
  for (let i = windowSize; i < data.length; i++) {
    X.push(data.slice(i - windowSize, i))
    y.push(data[i])
  }
  
  return { X, y }
}

8.1 RETRY COM BACKOFF EXPONENCIAL
-------------------------------------------------------------------------------

Implementação:
-------------------------------------------------------------------------------
async function fetchWithRetry<T>(
  fn: () => Promise<T>,
  maxRetries: number = 3,
  baseDelay: number = 1000
): Promise<T> {
  let lastError: Error | null = null
  
  for (let i = 0; i < maxRetries; i++) {
    try {
      return await fn()
    } catch (error) {
      lastError = error as Error
      const delay = baseDelay * Math.pow(2, i)
      logger.warn(`Tentativa ${i + 1}/${maxRetries} falhou. Retentando em ${delay}ms`)
      await new Promise(resolve => setTimeout(resolve, delay))
    }
  }
  
  throw lastError
}
-------------------------------------------------------------------------------

Uso:

async function fetchWithTimeout<T>(
  promise: Promise<T>,
  timeoutMs: number = 30000
): Promise<T> {
  let timeoutId: NodeJS.Timeout
  
  const timeoutPromise = new Promise<never>((_, reject) => {
    timeoutId = setTimeout(() => {
      reject(new Error(`Timeout após ${timeoutMs}ms`))
    }, timeoutMs)
  })
  
  try {
    const result = await Promise.race([promise, timeoutPromise])
    clearTimeout(timeoutId)
    return result as T
  } catch (error) {
    clearTimeout(timeoutId)
    throw error
  }
}

8.3 CIRCUIT BREAKER
-------------------------------------------------------------------------------

Implementação para prevenir chamadas excessivas a APIs com falha:
-------------------------------------------------------------------------------
class CircuitBreaker {
  private failures: number = 0
  private lastFailureTime: number = 0
  private state: 'CLOSED' | 'OPEN' | 'HALF_OPEN' = 'CLOSED'
  private readonly failureThreshold: number = 5
  private readonly timeoutMs: number = 60000

  async execute<T>(fn: () => Promise<T>): Promise<T> {
    if (this.state === 'OPEN') {
      if (Date.now() - this.lastFailureTime > this.timeoutMs) {
        this.state = 'HALF_OPEN'
        logger.info('Circuit breaker: HALF_OPEN')
      } else {
        throw new Error('Circuit breaker está OPEN')
      }
    }
    
    try {
      const result = await fn()
      if (this.state === 'HALF_OPEN') {
        this.state = 'CLOSED'
        this.failures = 0
        logger.info('Circuit breaker: CLOSED')
      }
      return result
    } catch (error) {
      this.failures++
      this.lastFailureTime = Date.now()
      
      if (this.failures >= this.failureThreshold) {
        this.state = 'OPEN'
        logger.warn('Circuit breaker: OPEN')
      }
      throw error
    }
  }
}

10.1 SERVIÇO DE PREÇOS (price.service.ts)

import { logger } from '../utils/logger'
import { traceSync, generateTraceId } from '../utils/tracer'

interface PriceCache {
  price: number
  timestamp: number
}

const priceCache = new Map<string, PriceCache>()
const PRICE_CACHE_DURATION = 5000 // 5 segundos

export async function getCurrentPrice(
  userId: string,
  pair: string,
  apiKey: string,
  secretKey: string
): Promise<number> {
  const traceId = generateTraceId()
  traceSync(userId, 'DEBUG', 'price', 'getCurrentPrice', `Buscando preço para ${pair}`, 0, { traceId })
  
  // Verificar cache
  const cached = priceCache.get(pair)
  if (cached && Date.now() - cached.timestamp < PRICE_CACHE_DURATION) {
    traceSync(userId, 'DEBUG', 'price', 'getCurrentPrice', `Cache hit para ${pair}`, 0, { traceId })
    return cached.price
  }
  
  try {
    const symbol = pair.replace('/', '')
    const url = `${process.env.BINANCE_BASE_URL}/api/v3/ticker/price?symbol=${symbol}`
    
    const response = await fetch(url)
    const data = await response.json()
    const price = parseFloat(data.price)
    
    // Atualizar cache
    priceCache.set(pair, { price, timestamp: Date.now() })
    
    traceSync(userId, 'DEBUG', 'price', 'getCurrentPrice', `Preço ${pair}: ${price}`, 0, { traceId })
    return price
  } catch (error) {
    traceSync(userId, 'DEBUG', 'price', 'getCurrentPrice', `Erro: ${error}`, 0, { traceId, errorFlag: true })
    throw error
  }
}

import crypto from 'crypto'
import { binanceLimiter, orderLimiter } from '../utils/rateLimiter'

export async function executeOrder(
  userId: string,
  pair: string,
  side: 'BUY' | 'SELL',
  quantity: number,
  price: number | undefined,
  apiKey: string,
  secretKey: string
): Promise<OrderResult> {
  const traceId = generateTraceId()
  traceSync(userId, 'TRACE', 'order', 'executeOrder', `Executando ${side} ${quantity} ${pair}`, 0, { traceId })
  
  // Aguardar rate limit
  await binanceLimiter.waitForWeight(1)
  if (price) {
    await orderLimiter.waitForOrder()
  }
  
  const symbol = pair.replace('/', '')
  const timestamp = Date.now()
  
  let params: Record<string, any> = {
    symbol,
    side,
    type: price ? 'LIMIT' : 'MARKET',
    quantity: quantity.toString(),
    timestamp,
    recvWindow: 5000
  }
  
  if (price) {
    params.price = price.toString()
    params.timeInForce = 'GTC'
  }
  
  const queryString = new URLSearchParams(params).toString()
  const signature = crypto
    .createHmac('sha256', secretKey)
    .update(queryString)
    .digest('hex')
  
  const url = `${process.env.BINANCE_BASE_URL}/api/v3/order?${queryString}&signature=${signature}`
  
  const response = await fetch(url, {
    method: 'POST',
    headers: { 'X-MBX-APIKEY': apiKey }
  })
  
  const result = await response.json()
  
  if (response.ok) {
    traceSync(userId, 'DEBUG', 'order', 'executeOrder', `Ordem executada: ${result.orderId}`, 0, { traceId })
    
    // Enviar webhook
    await sendWebhook('order.executed', {
      orderId: result.orderId,
      pair,
      side,
      quantity,
      price,
      status: 'FILLED'
    })
    
    return { success: true, orderId: result.orderId, executedQty: parseFloat(result.executedQty) }
  } else {
    traceSync(userId, 'DEBUG', 'order', 'executeOrder', `Erro: ${result.msg}`, 0, { traceId, errorFlag: true })
    
    // Enviar webhook de erro
    await sendWebhook('order.failed', {
      pair,
      side,
      quantity,
      price,
      error: result.msg,
      code: result.code
    })
    
    return { success: false, error: result.msg, code: result.code }
  }
}

export async function collectTrainingData(
  sessionId: string,
  config: TrainingConfig
): Promise<Dataset> {
  const allData = []
  
  for (const pair of config.includedPairs) {
    logger.info(`Coletando dados para ${pair}`)
    
    const candles = await fetchHistoricalCandles(
      pair,
      config.timeframe,
      config.trainingPeriod.startDate,
      config.trainingPeriod.endDate
    )
    
    // Calcular indicadores
    const withIndicators = calculateIndicators(candles, config.indicators)
    
    allData.push(...withIndicators)
  }
  
  // Normalizar dados
  const normalized = normalizeData(allData)
  
  // Criar sequências para LSTM
  const sequences = createSequences(normalized, config.hyperparameters.windowSize)
  
  // Dividir treino/validação
  const splitIndex = Math.floor(sequences.X.length * 0.8)
  
  const dataset = {
    trainX: sequences.X.slice(0, splitIndex),
    trainY: sequences.y.slice(0, splitIndex),
    valX: sequences.X.slice(splitIndex),
    valY: sequences.y.slice(splitIndex)
  }
  
  // Salvar dataset (opcional)
  await saveDataset(sessionId, dataset)
  
  return dataset
}

async function fetchHistoricalCandles(
  pair: string,
  interval: string,
  startDate: string,
  endDate: string
): Promise<CandleData[]> {
  const symbol = pair.replace('/', '')
  const startTime = new Date(startDate).getTime()
  const endTime = new Date(endDate).getTime()
  
  let allCandles: CandleData[] = []
  let currentStart = startTime
  
  while (currentStart < endTime) {
    const url = `${process.env.BINANCE_BASE_URL}/api/v3/klines?symbol=${symbol}&interval=${interval}&startTime=${currentStart}&limit=1000`
    
    const response = await fetch(url)
    const data = await response.json()
    
    if (data.length === 0) break
    
    const candles = data.map((candle: any) => ({
      timestamp: new Date(candle[0]),
      open: parseFloat(candle[1]),
      high: parseFloat(candle[2]),
      low: parseFloat(candle[3]),
      close: parseFloat(candle[4]),
      volume: parseFloat(candle[5])
    }))
    
    allCandles = [...allCandles, ...candles]
    currentStart = data[data.length - 1][0] + 1
  }
  
  return allCandles
}
