# Comandos operacionais do backend

## Opcao recomendada: bootstrap completo do projeto

```powershell
cd D:\Projetos\bot-cripto-ia
.\init.ps1
```

## Subida manual do backend

```powershell
cd D:\Projetos\bot-cripto-ia\backend
npm install
npx prisma generate
npm run prisma:deploy
npm run seed
npm run dev
```

## Subida com Docker Compose

```powershell
cd D:\Projetos\bot-cripto-ia
docker compose up --build
```

## Comandos uteis de manutencao

```powershell
cd D:\Projetos\bot-cripto-ia\backend
npm run test:run
npm run build
npx prisma migrate status
```
