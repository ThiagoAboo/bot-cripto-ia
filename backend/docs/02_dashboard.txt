================================================================================
TELA: DASHBOARD E COCKPIT DE BOTS
================================================================================

Este arquivo descreve os endpoints que alimentam:
- dashboard geral
- cards de saldo e performance
- lista de bots
- tela detalhada `/bots`

-------------------------------------------------------------------------------
1. GET /api/dashboard/total-balance
-------------------------------------------------------------------------------

Descricao:
- retorna o resumo do patrimonio do usuario
- considera `available + reserved`
- usa cotacao atual para valorar a carteira

Campos esperados:
- `totalBrl`
- `dailyProfitBrl`
- `dailyProfitPercent`
- `totalPnlBrl`
- `totalPnlPercent`
- `hitRate`
- `usdtBrlRate`
- `lastUpdate`

-------------------------------------------------------------------------------
2. GET /api/dashboard/currencies-balance
-------------------------------------------------------------------------------

Descricao:
- retorna saldo detalhado por moeda
- mantem ativos visiveis mesmo quando `available = 0` e ainda houver `reserved`

Uso principal:
- cards de saldo por moeda
- apoio para transacoes e valorizacao

-------------------------------------------------------------------------------
3. GET /api/dashboard/transactions/recent
-------------------------------------------------------------------------------

Descricao:
- retorna as transacoes mais recentes para o dashboard
- alias funcional de `GET /api/dashboard/recent-transactions`

-------------------------------------------------------------------------------
4. GET /api/dashboard/bots-status
5. GET /api/dashboard/bots
-------------------------------------------------------------------------------

Descricao:
- retornam a lista da frota de bots do usuario
- o frontend usa esses endpoints para o painel principal e para a rota `/bots`

Campos relevantes por item:
- `id`
- `name`
- `strategy`
- `templateId`
- `templateName`
- `indicatorType`
- `executionMode`
- `status`
- `isPaused`
- `focusPair`
- `currentPair`
- `recommendedAction`
- `confidence`
- `modelReady`
- `paperReadiness`

Observacoes:
- `Bot` representa a instancia operacional
- `BotTemplate` representa o catalogo base de especialistas
- bots do sistema podem ser materializados em bots customizados do usuario ao salvar alteracoes

-------------------------------------------------------------------------------
6. GET /api/dashboard/bots/templates
-------------------------------------------------------------------------------

Descricao:
- retorna o catalogo de templates especializados
- usado na criacao de novos bots na interface

-------------------------------------------------------------------------------
7. GET /api/dashboard/bots/worker-status
-------------------------------------------------------------------------------

Descricao:
- informa se o worker interno do backend esta rodando

Uso:
- badge de saude operacional na tela `/bots`

-------------------------------------------------------------------------------
8. GET /api/dashboard/bots/:id
-------------------------------------------------------------------------------

Descricao:
- retorna o detalhe completo da instancia do bot

Campos relevantes:
- metadados da instancia
- template herdado
- `templateParameters`
- `instanceParameters`
- `effectiveParameters`
- `effectiveAllowedPairs`
- `allowedPairsSource`
- `paperReadiness`
- `modelReady`
- `operationalBlockReason`

-------------------------------------------------------------------------------
9. GET /api/dashboard/bots/:id/history
-------------------------------------------------------------------------------

Descricao:
- retorna historico operacional do bot

Blocos principais:
- `transactions`
- `traces`
- `trainingSessions`
- `decisions`
- `decisionSummary`
- `paperReadiness`

Uso:
- abas de historico, sinais, traces e treinos na rota `/bots`

-------------------------------------------------------------------------------
10. GET /api/dashboard/bots/:id/models
-------------------------------------------------------------------------------

Descricao:
- retorna o catalogo de artefatos de modelo do bot

Campos principais:
- `items[]`: artefatos `champion`, `challenger` e `archived`
- `governance`: resumo de elegibilidade e politica

Uso:
- governanca de modelos na rota `/bots`

-------------------------------------------------------------------------------
11. GET /api/dashboard/bots/:id/analysis
-------------------------------------------------------------------------------

Descricao:
- executa uma analise seca do bot sem enviar ordem
- atualiza `currentPair`, `recommendedAction`, `confidence` e `lastAnalysis`

Uso:
- radar operacional
- preview da camada `bots`

-------------------------------------------------------------------------------
12. POST /api/dashboard/bots
-------------------------------------------------------------------------------

Descricao:
- cria uma nova instancia a partir de um template

Entradas tipicas:
- `templateId`
- `name`
- `description`
- `executionMode`
- `status`
- `parameters`

-------------------------------------------------------------------------------
13. PUT /api/dashboard/bots/:id
-------------------------------------------------------------------------------

Descricao:
- atualiza a instancia do bot

Regras importantes:
- bot do sistema pode ser materializado como bot customizado do usuario
- `full_auto` continua bloqueado quando o bot nao for elegivel

-------------------------------------------------------------------------------
14. DELETE /api/dashboard/bots/:id
-------------------------------------------------------------------------------

Descricao:
- remove instancia customizada do usuario

Observacao:
- nao e a remocao do catalogo global seedado

-------------------------------------------------------------------------------
15. POST /api/dashboard/bots/:id/run
-------------------------------------------------------------------------------

Descricao:
- dispara manualmente um ciclo operacional

Comportamento por modo:
- `semi_auto`: so sugere
- `paper`: executa na carteira local
- `full_auto`: envia ordem real para Binance se o bot estiver elegivel

Guardrails aplicados antes da execucao:
- champion sincronizado
- modelo operacional pronto
- criterios minimos de `paperReadiness`
- circuit breaker
- exposicao maxima
- correlacao
- filtros da Binance (`stepSize`, `tickSize`, `minQty`, `minNotional`)

-------------------------------------------------------------------------------
16. POST/PUT /api/dashboard/bots/:id/pause
17. POST/PUT /api/dashboard/bots/:id/resume
-------------------------------------------------------------------------------

Descricao:
- pausa ou retoma a instancia

Campos afetados:
- `isPaused`
- `updatedAt`

-------------------------------------------------------------------------------
18. POST /api/dashboard/bots/:id/models/:modelId/promote
19. POST /api/dashboard/bots/:id/models/:modelId/archive
-------------------------------------------------------------------------------

Descricao:
- promove challenger para champion
- arquiva artefato inativo

Regras:
- nao e permitido arquivar o champion ativo
- promocao atualiza `Bot.modelVersion` e `Bot.modelUrl`

-------------------------------------------------------------------------------
20. GET /api/dashboard/performance
-------------------------------------------------------------------------------

Descricao:
- retorna a serie de performance para o grafico do dashboard

Comportamento operacional:
- o backend pode semear novo snapshot mesmo sem mudanca de valor se o ponto anterior estiver velho demais
- isso evita grafico parado em periodos mais longos sem mutacao

Periodos aceitos:
- `24h`
- `7d`
- `30d`
- `total`

-------------------------------------------------------------------------------
21. BLOQUEIO DE FULL_AUTO
-------------------------------------------------------------------------------

O backend nao libera `full_auto` somente porque o usuario selecionou esse modo.

Hoje a elegibilidade depende de:
- champion valido
- modelo operacional pronto
- sincronizacao entre bot e champion atual
- `paperReadiness.readyForFullAuto = true`

Mensagens de bloqueio sao devolvidas ao frontend para orientar a tela `/bots`.
