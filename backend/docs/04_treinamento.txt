Descrição: Cria uma nova sessão de treinamento

  "modelVersion": "v1.0.0",
  "baseModelId": "session_0",
  "dataSource": "exchange",
  "trainingPeriod": {
    "startDate": "2024-01-01",
    "endDate": "2024-03-31"
  },
  "includedPairs": ["BTC/USDT", "ETH/USDT"],
  "indicators": ["RSI", "MACD", "SMA"],
  "timeframe": "1h",
  "hyperparameters": {
    "hiddenLayers": 2,
    "neuronsPerLayer": [64, 32],
    "dropoutRate": 0.2,
    "activation": "relu",
    "batchSize": 32,
    "epochs": 100,
    "learningRate": 0.001,
    "optimizer": "adam",
    "lossFunction": "mse",
    "validationSplit": 20,
    "earlyStopping": {
      "enabled": true,
      "patience": 10
    }
  }
}

RESPONSE (200 - Sucesso):
{
  "success": true,
  "data": {
    "id": "session_123",
    "botId": "bot1",
    "strategyId": "template_macd_momentum",
    "strategyName": "MACD Momentum Specialist",
    "status": "pending",
    "startTime": "2024-01-15T10:30:00Z",
    "config": { ... }
  }
}

- TrainingSession (criação)
- Bot (instância operacional)
- BotTemplate (validação de compatibilidade estratégica)

CAMPOS INSERIDOS:
- id (UUID)
- botId
- status = 'pending'
- startTime = now()

OBSERVAÇÃO:
- `botId` identifica a instância operacional do bot
- `strategyId` identifica o template estratégico compatível com a instância

8. API: POST /api/training/sessions/{id}/test
-------------------------------------------------------------------------------

Descrição: Executa backtesting com o modelo treinado

Observação operacional:
- quando `TRAINING_ML_ENGINE_PROVIDER=python`, o backtest usa engine real em Python
  (`scikit-learn` / `xgboost` / `torch`) para treinar no período histórico e inferir no
  período de teste, mantendo o contrato HTTP do backend

HEADERS:
  Authorization: Bearer {token}

PATH PARAMS:
  id: string (ID da sessão)

RESPONSE (200 - Sucesso):
{
  "success": true,
  "data": {
    "sessionId": "session_123",

    "maxDrawdown": -12.5,

9. API: POST /api/training/sessions/{id}/save
-------------------------------------------------------------------------------

Descrição: Salva permanentemente o modelo treinado

Observação operacional:
- quando o provider Python está ativo, este endpoint executa o treino real antes de
  persistir o artefato final
- o artefato salvo passa a incluir `enginePackage`, contendo o payload serializado do
  modelo para inferência posterior nos bots

HEADERS:
  Authorization: Bearer {token}

PATH PARAMS:
  id: string (ID da sessão)

RESPONSE (200 - Sucesso):
{
  "success": true,
  "data": {
    "modelUrl": "/models/session_123_final.h5",
    "autoPromoted": true,
    "governanceRole": "champion",
    "modelArtifactId": "artifact_123"
  }
}

TABELAS ENVOLVIDAS:
- TrainingSession (atualização)
- Bot (atualização)
- BotModelArtifact (criação/atualização)

CAMPOS ATUALIZADOS:

TrainingSession:
- modelUrl
- updatedAt

Bot:
- modelVersion
- modelUrl
- updatedAt

BotModelArtifact:
- modelVersion
- modelUrl
- governanceRole (`champion` / `challenger` / `archived`)
- isActive
- evaluationSummary
- reproducibilitySummary

REGRAS:
- se for o primeiro modelo salvo para o bot, o artefato entra como `champion`
  automaticamente (`autoPromoted = true`)
- se o bot já possuir `champion`, o novo artefato entra como `challenger`
- o runtime dos bots deve usar o `champion` ativo como referência operacional

-------------------------------------------------------------------------------
10. API: GET /api/training/sessions/{id}/download
-------------------------------------------------------------------------------

Descrição: Baixa o arquivo do modelo treinado

HEADERS:
  Authorization: Bearer {token}

PATH PARAMS:
  id: string (ID da sessão)

RESPONSE:
  Content-Type: application/octet-stream
  Content-Disposition: attachment; filename="model_session_123.h5"
  (arquivo binário)

Observação:
- o arquivo baixado continua sendo entregue como `application/octet-stream`, mas o
  conteúdo é um artefato JSON versionado com métricas, reprodutibilidade e, quando
  disponível, o `enginePackage` serializado do modelo real

TABELAS ENVOLVIDAS:
- TrainingSession (leitura do modelUrl)

12. MODELO DE DADOS - TrainingSession
-------------------------------------------------------------------------------

TABELA: TrainingSession

CAMPO               | TIPO      | OBRIG | DESCRIÇÃO
--------------------|-----------|-------|----------------------------------
id                  | String    | Sim   | UUID - Chave primária
botId               | String    | Sim   | FK para Bot
status              | String    | Sim   | pending/running/paused/completed/failed/cancelled
startTime           | DateTime  | Sim   | Data de início
endTime             | DateTime  | Não   | Data de término
config              | String    | Sim   | JSON com configuração
metrics             | String    | Sim   | JSON array de métricas
bestEpoch           | Int       | Não   | Melhor época
bestValLoss         | Float     | Não   | Melhor loss de validação
modelUrl            | String    | Não   | URL do modelo salvo
createdAt           | DateTime  | Sim   | Data de criação
updatedAt           | DateTime  | Sim   | Data de atualização

-------------------------------------------------------------------------------
13. MODELO DE DADOS - BotModelArtifact
-------------------------------------------------------------------------------

TABELA: BotModelArtifact

CAMPO                   | TIPO      | OBRIG | DESCRIÇÃO
------------------------|-----------|-------|----------------------------------
id                      | String    | Sim   | UUID/CUID do artefato
userId                  | String    | Sim   | FK para User
