-------------------------------------------------------------------------------
1. API: GET /api/logs
-------------------------------------------------------------------------------

Descrição: Retorna lista de logs com paginação e filtros

HEADERS:
  Authorization: Bearer {token}

QUERY PARAMS:
  page: number (padrão: 1)
  limit: number (padrão: 50)
  levels: string (opcional, ex: INFO,WARN,ERROR)
  modules: string (opcional, ex: dashboard,bot)
  startDate: string (opcional, ISO date)
  endDate: string (opcional, ISO date)
  search: string (opcional)

RESPONSE (200 - Sucesso):
{
  "success": true,
  "data": {
    "items": [
      {
        "id": "log_001",
        "timestamp": "2024-01-15T10:30:00Z",
        "level": "INFO",
        "module": "bot",
        "message": "Bot Scalper V2 iniciou análise de mercado",
        "details": {
          "strategy": "scalper",
          "pairs": ["BTC/USDT", "ETH/USDT"]
        }
      }
    ],
    "total": 1520,
    "page": 1,
    "limit": 50,
    "totalPages": 31
  }
}

TABELAS ENVOLVIDAS:
- Log

CAMPOS RETORNADOS:
- id
- timestamp
- level
- module
- message
- details (JSON)

-------------------------------------------------------------------------------
2. API: GET /api/traces
-------------------------------------------------------------------------------

Descrição: Retorna lista de traces com paginação e filtros

HEADERS:
  Authorization: Bearer {token}

QUERY PARAMS:
  page: number (padrão: 1)
  limit: number (padrão: 50)
  levels: string (opcional, ex: DEBUG,TRACE)
  modules: string (opcional)
  traceId: string (opcional)
  functionName: string (opcional)
  botId: string (opcional)
  currentPair: string (opcional)
  recommendedAction: string (opcional, buy/sell/hold)
  minDurationMs: number (opcional)
  onlyErrors: boolean (opcional)
  startDate: string (opcional)
  endDate: string (opcional)
  search: string (opcional)

RESPONSE (200 - Sucesso):
{
  "success": true,
  "data": {
    "items": [
      {
        "id": "trace_001",
        "timestamp": "2024-01-15T10:30:00Z",
        "level": "TRACE",
        "module": "bot",
        "traceId": "trc_abc123",
        "parentTraceId": null,
        "functionName": "BotScalper.executeAnalysis()",
        "message": "Iniciando análise de mercado",
        "durationMs": 0,
        "botId": "bot1",
        "currentPair": "BTC/USDT",
        "recommendedAction": null,
        "confidence": null,
        "errorFlag": false
      }
    ],
    "total": 8500,
    "page": 1,
    "limit": 50,
    "totalPages": 170
  }
}

TABELAS ENVOLVIDAS:
- Trace

CAMPOS RETORNADOS:
- id
- timestamp
- level
- module
- traceId
- parentTraceId
- functionName
- message
- durationMs
- botId
- currentPair
- recommendedAction
- confidence
- errorFlag

-------------------------------------------------------------------------------

Descrição: Retorna todos os traces agrupados por traceId

HEADERS:

7. MODELO DE DADOS - Log
-------------------------------------------------------------------------------

TABELA: Log

CAMPO           | TIPO      | OBRIG | DESCRIÇÃO
----------------|-----------|-------|----------------------------------
id              | String    | Sim   | UUID - Chave primária
timestamp       | DateTime  | Sim   | Data/hora do evento
level           | String    | Sim   | INFO, WARN, ERROR
module          | String    | Sim   | dashboard/configurations/training/transactions/bot/system/api/database
message         | String    | Sim   | Mensagem descritiva
details         | String    | Não   | JSON com detalhes adicionais
userId          | String    | Sim   | FK para User
createdAt       | DateTime  | Sim   | Data de criação

EXEMPLO DE REGISTRO:

{
  "id": "log_001",
  "timestamp": "2024-01-15T10:30:00Z",
  "level": "INFO",
  "module": "bot",
  "message": "Bot Scalper V2 iniciou análise de mercado",
  "details": "{\"strategy\":\"scalper\",\"pairs\":[\"BTC/USDT\"]}",
  "userId": "user_001",
  "createdAt": "2024-01-15T10:30:00Z"
}

8. MODELO DE DADOS - Trace
-------------------------------------------------------------------------------

TABELA: Trace

CAMPO               | TIPO      | OBRIG | DESCRIÇÃO
--------------------|-----------|-------|----------------------------------
id                  | String    | Sim   | UUID - Chave primária
timestamp           | DateTime  | Sim   | Data/hora do passo
level               | String    | Sim   | DEBUG, TRACE
module              | String    | Sim   | Módulo de origem
traceId             | String    | Sim   | ID único da execução
parentTraceId       | String    | Não   | ID do trace pai
functionName        | String    | Sim   | Nome da função/método
message             | String    | Sim   | Mensagem descritiva
durationMs          | Float     | Sim   | Duração desde o início (ms)
botId               | String    | Não   | FK para Bot
currentPair         | String    | Não   | Moeda sendo analisada
recommendedAction   | String    | Não   | buy/sell/hold
confidence          | Float     | Não   | Confiança (0-100)
errorFlag           | Boolean   | Sim   | Se houve erro
userId              | String    | Sim   | FK para User
createdAt           | DateTime  | Sim   | Data de criação

ÍNDICES:
- INDEX ON (traceId)
- INDEX ON (timestamp)
- INDEX ON (botId)
- INDEX ON (userId)

EXEMPLO DE REGISTRO:

{
  "id": "trace_001",
  "timestamp": "2024-01-15T10:30:00Z",
  "level": "TRACE",
  "module": "bot",
  "traceId": "trc_abc123",
  "parentTraceId": null,
  "functionName": "BotScalper.executeAnalysis()",
  "message": "Iniciando análise de mercado",
  "durationMs": 0,
  "botId": "bot1",
  "currentPair": "BTC/USDT",
  "recommendedAction": null,
  "confidence": null,
  "errorFlag": false,
  "userId": "user_001",
  "createdAt": "2024-01-15T10:30:00Z"
}
